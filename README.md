# What this Program is For

This script is designed to help you practice a combined memory system that turns numbers (abstract and difficult to remember on their own) into much more memorable phrases/word pictures.

**For exmaple,** the number sequence 227244 becomes 'nun, shooting, carrier', and 670061 'chick, eating, usain bolt'. 

This is a combined memory system: 

- The major system
- The Person, Action, Object system (PAO)
- Number peg system

### 1. The Major system
The major system is a phonetic way of linking numbers and letters:

0: s, z  
1: t, d (or 'th')  
2: n  
3: m  
4: r  
5: l  
6: ch, sh, or j  
7: k, g  
8: f, v  
9: p, b  

Note how the letters are phonetically similar, often occuring in voiced/unvoiced pairs. 

In the major system, you link digit pairs together to form words. For example, 24 would be 'n' and 'r', or 'nero' and 55 would be 'l' and 'l', or 'lilac'. 

### 2. The PAO System

The PAO system (person, action, object) expands on the concept of the major system. Every single number pair, from 00-99 is asigned a person, action, and object.

For example, in the PAO system, 24 isn't just 'nero'. It's 'nero (P), ruling(A), rome'(O). 

The number 55 isn't just 'lilac', but 'lilac (P), blooming (A), green gables (O)

Note: the definition for the "Person" is somewhat lose. It doesn't have to be a literal person, but anything that can perform an action (i.e. pretty much anything).

**Example**: let's take the 6-digit number: 245543  
`24 = ['nero', 'ruling', 'rome']`  
`55 = ['lilac', 'blooming', 'green gables']`  
`43 = ['ram', 'climbing', 'cliff']`

We always form PAO phrases in order of person, action, object, so let's seperate the number 245543 into 24-55-43.  

P for 24: nero  
A for 55: blooming  
O for 43: cliff 

So our phrase would become, 'nero, blooming, cliff'. 

### 3. The Number Peg System

Since these number systems are designed to work in digit pairs, a third system is required to handle odd numbers of digits. 

Numbers are paired together, and the last digit is remembered with a 'peg', or look-alike object.

for example, 137 becomes 13-7, and 48839 becomes 48-83-9 (note how the last number becomes a loner. This is the digit we'll remember with a peg.)

**Pegs:**  
0: donut  
1: candle   
3: handcuffs  
4: sailboat  
5: snake  
6: elephant  
7: boomerang  
8: snowman  
9: balloon 

With the combined system, 48-83-9 becomes 'rover, x-raying, balloon'. 

# About the Script

While I include my personal database for all the number pairs 00-99 with their respective P, A, and O, it's really intended for use...for myself. 

If you want to learn this number system, you should know a few things...

- You need to come up with your _own_ number pairs 00-99 for this to be effective for your use
- You don't have to use a combined system like I do. For example, you could just use a number peg system (far easier), or just the major system
- It takes a lot of effort to memorize a PAO list, and for it to actually be useful. 

If you're interested in creating your own version, you'll need to enter in your own unique database of PAO phrases (i.e. create a spread sheet and ask ChatGPT to create a dictionary of numbers and phrases for you).
